# اسکنر کریپتو - تحلیل چند تایم فریم + نقدینگی + Order Book

رباتی که هر 4 ساعت به‌صورت خودکار بازار کریپتو را اسکن کرده و 10 پیشنهاد لانگ و 10 پیشنهاد شورت با نقاط ورود، استاپ لاس و اهداف سود به کانال تلگرام شما ارسال می‌کند.

## ویژگی‌ها

- **تحلیل چند تایم فریم** (Top-Down): 1d → 4h → 1h → 15m
- **تحلیل نقدینگی**: MFI, OBV, CMF, ADL, تشخیص انباشت/توزیع
- **تحلیل Order Book**: فشار خرید/فروش، دیوارهای نقدینگی
- **تحلیل حجم ورود**: بررسی حجم در 1h و 15m برای تایید نقطه ورود
- **تقویم رویدادهای اقتصادی**: FOMC, CPI, NFP, PPI, GDP + هشدار و راهنمایی
- **محاسبه نقطه ورود و استاپ لاس**: ATR + حمایت/مقاومت + Order Book
- **خروجی PDF و Excel** با دلایل کامل انتخاب
- **ارسال خودکار به تلگرام** با خلاصه، PDF و Excel
- **فیلتر استیبل‌کوین‌ها** (USDT, USDC, USDE و...)
- **حداقل مارکت کپ 100 میلیون دلار**

## راه‌اندازی

### 1. کلون Repository

```bash
git clone https://github.com/YOUR_USERNAME/crypto-scanner.git
cd crypto-scanner
```

### 2. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 3. تنظیم تلگرام

1. با **@BotFather** یک ربات بسازید و Bot Token دریافت کنید
2. ربات را به کانال خود به‌عنوان Administrator اضافه کنید
3. در GitHub Repository → Settings → Secrets and variables → Actions:
   - `TELEGRAM_BOT_TOKEN` = توکن ربات شما
   - `TELEGRAM_CHAT_ID` = `@your_channel_name` یا chat_id

### 4. فعال‌سازی GitHub Actions

1. به تب **Actions** بروید
2. اگر هشدار بود، **Enable workflows** را بزنید
3. برای تست دستی: **Run Workflow** را بزنید

## اجرای محلی

```bash
# اجرای کامل + ارسال به تلگرام
python3 run_scheduled.py

# فقط اسکن بدون تلگرام
python3 main.py

# تست اتصال تلگرام
python3 test_telegram.py

# اجرای زمان‌بند دائمی (برای سرور)
python3 scheduler_daemon.py
```
